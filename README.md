# BodhiArts Yoga Yard (菩提艺术瑜伽) - website prototype

Date: 2026-11-02 (published to GitHub 2026-11-11)

A static prototype of the bilingual (Chinese / English) website for BodhiArts Yoga Yard, made by Hypha. It is a prototype only and is not the live site. The class times and contact details on it are examples.

- The site is a single file: `index.html`. Open it in a browser, or view it on GitHub Pages.
- The sample photos are from Wikimedia Commons (CC BY-SA 4.0). See `assets/CREDITS.txt`. They will be replaced with the teacher's own photos before launch.
- The page is set to noindex, so search engines don't list it.
